# Lumo — Android releases

This public repository contains installable Android APK releases for Lumo.

- Download the latest version from [Releases](https://github.com/IslomKhovaling/Lumo-Releases/releases/latest).
- The application source code is maintained separately in a private repository.
- New APK releases are published automatically after a successful build when the publishing secret is configured.

To install, download the APK on your Android device and follow the Android installation prompts. Android may require permission to install apps from your browser or file manager.
